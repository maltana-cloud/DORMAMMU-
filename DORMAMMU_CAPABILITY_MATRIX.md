## Highest-priority gaps

1. **Model/agent/specialist routing:** the operating path is now verified, but it does not yet dynamically select the best available intelligence capability for a task.
2. **Controlled reflection/learning:** improvement proposals are recorded, but DORMAMMU does not yet learn bounded strategy/policy changes from verified outcomes.
3. **Evidence-backed arbitrary natural-language goal understanding:** the safe operating path currently consumes explicit structured goals/actions rather than inferring arbitrary high-impact intent.
4. **Production capability source configuration:** generic JSON/HTTPS catalog scouts exist; real external sources still need explicit trusted-source configuration and source-specific validation.
5. **Broad ecosystem capabilities:** communication, community, creation, distribution, awareness, business/reinvestment, media, gaming, language/speech, and model evolution remain incomplete.

## Blocked vs not built

The matrix does not mark missing credentials or platform verification as software failures. Those become `BLOCKED` only when the software is ready and an external owner/platform action is genuinely required.

At this checkpoint no listed major capability is `BLOCKED`; several are simply not built yet.

## Verification rule

`TESTED` means meaningful repository tests exist and have passed. `VERIFIED` requires stronger integration/operational evidence appropriate to the capability. `DEPLOYED` requires an authorized real deployment. Documentation, imports, or a green unit test alone never constitute production proof.
